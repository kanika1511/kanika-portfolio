# Kanika  — UI/UX Designer & Frontend Product Engineer

A modern, accessible, and high-performance portfolio website showcasing UI/UX case studies, design systems, interactive prototypes, and production engineering.

## 🚀 Live Demo
- **Portfolio**: Deployed via [Vercel](https://vercel.com)

## ✨ Highlights
- **Design Systems & Tokens**: Custom CSS token architecture with dark/light themes, typography scales, and fluid responsive layouts.
- **Interactive UI Sandbox**: Live interactive components demonstrating component state management and Micro-interactions.
- **Accessibility (A11y)**: WCAG compliant contrast ratios, full keyboard navigation, ARIA semantics, and screen reader friendliness.
- **Performance**: Vanilla HTML5, modern CSS3, and modular ES6 JavaScript with zero bulky runtime dependencies.

## 🛠 Tech Stack
- **Design**: Figma, Human-Centered Design, Wireframing, Rapid Prototyping
- **Frontend**: HTML5, Modern CSS (Design Tokens, Grid, Flexbox), Vanilla JavaScript (ES6+)
- **Hosting & CI/CD**: Vercel

## 📂 Project Structure
```text
├── index.html        # Main portfolio entry point
├── vercel.json       # Vercel deployment configuration & caching headers
├── css/
│   ├── tokens.css    # Color tokens, typography, spacing, and theme variables
│   ├── main.css      # Core layouts, typography, and utility classes
│   └── components.css# Modular component styling (cards, modals, badges)
├── js/
│   ├── main.js       # Navigation, scroll observers, and theme controller
│   ├── sandbox.js    # Interactive UI component sandboxes
│   ├── audio.js      # Subtle UI micro-sound feedback
│   └── telemetry.js  # Client analytics and event tracking
└── assets/           # Optimized images and media assets
```
